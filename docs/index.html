마디순수 Rust 로 만든 한국어 형태소 분석기

문장을 어절로, 어절을 형태소로 나누고 세종 품사 표지를 붙입니다. 국립국어원 모두의 말뭉치 형태 분석 지침을 따릅니다. Python 패키지, Rust 라이브러리, 명령줄 도구가 모두 같은 결과를 냅니다.

madi 기본 설정(사전 + n-gram LM + 신경망 LM)의 실제 출력입니다. 겹줄은 어절 경계, 표지에 마우스를 올리면 정식 이름이 보입니다. 축약된 활용형(신다 = 시 + ㄴ다, 들어 = 듣 + 어)은 원형으로 풀어 냅니다.

무엇을 하나

모두의 말뭉치 지침을 따르는 분석

세종 품사 표지(NNG, VV, EF …)로 분석합니다. 2018 지침이 기본이고, 2025년판 형태 분석 지침식 출력(복합 명사 합치기 등)도 고를 수 있습니다.

두 단계 탐색

사전으로 격자를 만들고, 연접 비용으로 가망 없는 후보를 거른 뒤 형태소 n-gram LM 과 작은 신경망 LM 으로 다시 채점합니다. 앞뒤 양방향 점수로 한 번 더 걸러 LM 질의를 줄입니다.

정밀 모드

점수 차가 작은 어절만 작은 트랜스포머 교사로 다시 고릅니다. 동사·형용사, 불규칙 활용처럼 헷갈리는 자리에서 정확도가 오르고, 대신 느려집니다.

형태소로 나누는 문장 분리

마침표가 없는 구어 문장도 종결 어미를 보고 나눕니다. 규칙만 쓰는 빠른 분리도 함께 있습니다.

사용자 사전

단어, 기분석 항목, 분석 고치기 규칙을 파일로 더할 수 있습니다.

판본 문자열

사전·모델 파일과 설정을 해시로 묶은 문자열(0.3.0+d7f9f.r4p.f11…)을 냅니다. 두 분석 결과가 같은 판에서 나왔는지 바로 확인할 수 있습니다.

설치

PYTHON 3.9+ · Windows · macOS · Linux 
pip install madipy

import madi
m = madi.Analyzer()   # 처음 한 번 모델을 받는다
m.pos('아버지가 방에 들어가신다')
# [('아버지', '일반명'), ('가', '주격조'), …]
m.pos('아버지가', tags='code')
# [('아버지', 'NNG'), ('가', 'JKS')]

설치 이름은 madipy, 코드에서는 import madi. 모델(약 96 MB, 정밀 모드 +28 MB)은 처음 쓸 때 받습니다.

RUST 
cargo add madi
cargo install madi-cli

madi analyze --dict madi.dict --lm knlm.bin \
  --nlm model.nlm "아버지가 방에 들어가신다"

모델 파일은 Release 에서 받아 경로를 줍니다. API 문서는 docs.rs.

사용법

분석

tokenize 는 위치·어절 번호·문장 번호·원형이 든 Token 목록을, pos 는 (형태, 품사) 목록을 돌려줍니다. 문자열 목록을 주면 여러 스레드로 나눠 분석합니다.

문장 분리

split_into_sents 는 마침표가 없어도 종결 어미 뒤에서 끊고, 문장마다 원문 위치와 형태소를 줍니다.

여러 후보

analyze(text, top_n=3) 은 점수가 붙은 후보 분석을 좋은 것부터 돌려줍니다.

사용자 사전·불용어

사전 파일을 주거나 add_user_word 로 실행 중에 단어를 더합니다. madi.utils.Stopwords 로 조사·어미 같은 말을 뺍니다.

메서드 이름과 결과 꼴은 Kiwi(kiwipiepy)와 맞춰 두었습니다. 예와 출력이 모두 든 사용 안내는 PyPI 페이지에 있습니다.

성능

여러 분석기를 같은 잣대로 채점했습니다. 각 분석기의 태그를 세종 태그로 옮기고, 복합 명사 단위·숫자·기호처럼 분석기마다 관행이 갈리는 곳은 양쪽에서 똑같이 지웁니다. 차이는 Kiwi CoNg 대비이고, 괄호는 95% 구간입니다.

  • madi 는 0.3.0 공개판(모델 kword6) 기본 설정 그대로 쟀습니다(4p 가중, 전후향 가지치기 11, 정밀 τ 2.0·λ 0.3). 다른 분석기 줄은 2026-10-16 측정입니다.
  • 기본 모드는 모호성 벤치마크 kiwi510 에서 Kiwi 보다 낮습니다(0.7588 대 0.8275, p 0.0013). 정밀 모드는 같은 수준입니다(차이 유의하지 않음). 일반 문장의 형태소 F1 은 기본 모드도 앞섭니다.
  • 신문 420문장에서 madi 기본과 Kiwi CoNg 의 차(+0.35p)는 유의하지 않습니다. 정밀 모드의 차(+0.55p)는 유의합니다.
  • MP 2025 문어는 홀수 번째 문장으로 평가했고, 같은 기사의 짝수 번째 문장은 점수 가중 학습에 썼습니다.
  • 0.2.x(모델 kword5, 논문 판 — 전후향 가지치기 끔)와 비교하면 일반 문장 F1 은 같은 수준(문어 −0.02p, 구어 +0.04p)이고 kiwi510 기본이 +1.2p 입니다. kword6 는 개발용 문서를 모든 모델 입력에서 뺀 묶음입니다.
  • 속도·메모리: 노트북 1스레드, Python 바인딩, 분석 뒤 최대 RSS. Khaiii 는 같은 노트북의 WSL 에서 쟀습니다. JVM 분석기의 메모리는 JVM 힙을 포함합니다. Hannanum·Okt 는 세종 태그로 옮길 수 없어 표에서 뺐습니다.
  • 전후향 가지치기(τ 11)는 0.2.1 부터 기본입니다. 측정 셋 1만 7천 문장 중 5문장만 출력이 바뀌고, LM 질의가 44% 줄어 CLI 에서 약 17% 빨라집니다.
